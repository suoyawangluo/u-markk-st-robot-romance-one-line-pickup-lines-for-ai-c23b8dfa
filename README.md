One joke pickup line aimed at a robot/AI, written by `main.ts` to `/output/entry.txt`:

> I must be a prompt, because I can't stop thinking about how you'd complete me.

The line plays on prompts and completions — autocomplete as romance — instead of the worn battery/charging/reboot moves the judge brief warns against.

Run it with Node:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
